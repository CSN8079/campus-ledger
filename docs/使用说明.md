## 安卓 App 版

如果手机装的是 `dist/记账本-v1.1.5.apk`，那么：

- 不需要电脑，不需要 WiFi 或流量，飞行模式也能记账
- 数据存在手机本地，**卸载应用会一起删除**，请定期导出 JSON 备份
- 导出的 CSV / 备份文件会保存到系统的**「下载」**目录，文件管理器里能找到

## 第一次使用

打开应用后会自带一套「大学生常用」分类（14 个支出分类 + 8 个收入分类），
并自动创建一个当前学期。可以直接开始记账，也可以先到「设置」里按自己的习惯调整。

底部有四个标签：**概览 / 明细 / 统计 / 设置**，右下角的 **＋** 按钮随时可以记一笔。

> 在电脑上，按 `Ctrl + N` 也可以快速打开记账面板。

---

## 记一笔

1. 点右下角 **＋**
2. 选「支出」或「收入」
3. 填金额 → 选分类 → 改时间（默认现在）
4. 填 **来源**：这笔钱是给谁的 / 谁给的。例如 `校园食堂`、`美团`、`爸爸`
5. 填 **用途**：这笔钱用来干嘛。例如 `午餐`、`教材费`、`地铁`
6. 需要的话补个备注，点「保存」

「来源」和「用途」是两条独立的线索：
- 来源回答"钱和谁有关"
- 用途回答"钱花在哪"

统计页的「支出 TOP 来源」就是按来源聚合的，所以来源填得越规范，排行越有用。

---

## 选日期和时间

记账表单里的「时间」不是系统自带的日期控件，而是应用自己画的日历面板：

1. 点一下时间字段，从下方弹出日历
2. 上面有「今天 / 昨天 / 前天 / 一周前」的快捷按钮；点中间的「2026年10月」可以直接跳到任意年月
3. 下半部分选具体时间：有「现在 / 08:00 / 12:00 / 18:00 / 22:00」快捷选项，也可以逐格点选小时和分钟
4. 点「确定」回填；面板是独立浮层，**不会盖住你正在填的记账表单**

## 看懂明细页

顶部依次是：

| 控件 | 作用 |
| --- | --- |
| 周期 | 本周 / 本月 / 本学期 / 今年 / 全部 / 自定义日期 |
| 搜索框 | 搜索来源、用途、备注、分类、账户、标签 |
| 全部 / 支出 / 收入 | 按收支类型过滤 |
| 不计入统计：显示 / 不显示 | 切换报销、代付等「不计入统计」的账单是否显示在列表里。按钮上写的就是当前状态 |
| 已隐藏账单：显示 / 不显示 | 切换你手动隐藏的账单是否显示在列表里 |
| 按分类 / 按账户 | 多选筛选 |

列表按天分组，每天标题右侧会显示当天的收入与支出合计。

**点任意一条**可以看详情，并进行编辑、隐藏、删除、报销等操作。

金额上方的合计只统计"计入统计"的账单；如果有被排除的，下面会明确提示
「已有 N 笔（¥X）标记为不计入统计」。

## 报销：爸爸妈妈或别人帮着付的钱

这是最常用的场景。假设你买教材垫付了 320 元，之后找爸妈报销。

**情况一：先付钱，过几天才拿到报销款**

1. 正常记一笔支出：金额 320，分类「学习」，来源「教务处」，用途「教材费」
2. 在明细里点开这笔账单 → 点 **报销/排除**
3. 选「报销」→ 点「标记待报销」
   - 这笔支出**立刻从本月、本学期等所有合计里消失**，但记录还在
4. 收到钱的当天，在概览页点「待报销」提醒 → 去处理 → 找到这笔 → 点 **收到报销款**
5. 填到账金额、谁报销的、到账日期和账户 → 确认
   - 系统自动生成一笔「报销」收入，和原支出配成一组
   - **收入这笔也不计入统计**，所以本月账单完全不受影响

**情况二：一开始就知道是别人出钱**

直接在明细里点开那笔支出 → 报销/排除 → 选对应原因即可。

**其它可以选的原因**

| 原因 | 适用场景 |
| --- | --- |
| 报销 | 垫付后由父母 / 学校 / 单位报销 |
| 代付 | 帮同学代买，钱会还给你 |
| 借还款 | 借出去或还回来的钱 |
| 账户互转 | 自己从微信转到银行卡，不是真实消费 |
| 不计收支 | 其它不该算进收支的流水 |

**想反悔？** 点开那笔账单 → 「取消报销并恢复统计」，配对的报销收入会一起删掉。

## 隐藏某笔账单

如果某笔账单你既不想算进统计，也不想在明细里看到它：

点开账单 → **隐藏** → 之后明细默认不再显示。

需要看的时候，在明细页顶部打开「显示已隐藏账单」开关。

## 统计：周 / 月 / 学期

统计页支持这些周期：本周、本月、上月、**本学期**、今年、全部、自定义。

- **收入 / 支出 / 结余 / 日均支出** 四张卡片
- **支出构成 / 收入构成**：环形图 + 图例，显示每个分类的金额和占比
- **每日走势 / 每月走势**：红柱是支出，绿柱是收入
- **支出 TOP 来源**：哪些商家 / 人花得最多
- **支出账户分布**：钱主要从哪个账户出

页面顶部还有一个黄框，清楚写着「已从上方合计中排除：不计入统计 N 笔（¥X）；已隐藏 M 笔（¥Y）」，
所以你不会因为报销而看不懂自己的账。

> 周起始日可以在「设置 → 学期设置」里切换成周一或周日。

## 分类管理

**设置 → 管理支出分类 / 管理收入分类**

每个分类可以：
- 改名称、图标（60 个常用 emoji）、颜色
- **隐藏**：不再出现在记账和筛选的选择器里（历史账单照旧保留）
- **默认不计入统计**：这个分类下的账单默认被排除，适合「报销」这种分类

**套用预设包**可以一键补齐整套分类，已存在的同名分类会自动跳过：

| 预设包 | 内容 |
| --- | --- |
| 大学生常用（推荐） | 14 个支出分类 + 8 个收入分类 |
| 极简 7 类 | 餐饮、交通、学习、购物、娱乐、住宿、其他 |
| 细分开销 | 在常用基础上加订阅、健身、护肤、咖啡奶茶、资料打印 |

**自动分类规则**在「设置 → 管理自动分类规则」：写上关键词（逗号分隔），选好分类，
以后导入账单时命中关键词就会自动归类。自定义规则优先于内置规则。

---

## 学期设置

**设置 → 学期设置**，可以新增、编辑、删除学期，并指定哪一个作为「当前学期」。

统计页的「本学期」用的就是这里的日期范围。

默认规则（没有配置时）：2–6 月算春季学期，7–8 月算下一学年秋季学期，9 月–次年 1 月算秋季学期。

---

## 导出报表给家人看

**设置 → 导出报表给家人看**，或者直接在统计页点顶部的快捷按钮。

先选时间范围（本周 / 本月 / 上月 / 本学期 / 今年 / 全部 / 自定义），面板上会实时显示这个范围的
收入、支出和记录条数，确认无误后再选导出格式：

| 格式 | 内容 | 适合场景 |
| --- | --- | --- |
| **Excel 表格**（.xlsx） | 4 个工作表：周期汇总、账目明细、分类汇总、每日收支 | 自己存档、用电脑做进一步分析 |
| **图片报告**（.png） | 一页纸的收支报告：收支总览、分类占比、收支走势、支出 TOP 来源 | **直接发微信给爸妈看** |

**图片抬头可以自己写**：默认是「大学生活记账本」，在导出面板的「图片报告的抬头」里改成
「10 月生活费账目」「给爸妈看的账」之类都可以，最长 24 个字（太长会自动缩小字号）。
改过之后会记住，下次生成时自动带上；导出的文件名也会用这个抬头。

图片是浅色配色、单页排版，1080 像素宽，在手机上打开清晰，打印出来也不糊。
导出文件都在本机生成，不会上传。

## 自动备份

**设置 → 自动备份**。默认开启，按设定的间隔（12 小时 / 每天 / 3 天 / 每周）自动备份，
最多保留最近若干份（5 / 10 / 20 / 30 份），超出的自动清理。

三层保障：

| 位置 | 说明 |
| --- | --- |
| 应用内快照 | 整份数据存进本机数据库，随时可以还原到某个时间点 |
| 手机「下载」目录 | 安卓版每次自动备份时，还会写一份 `记账备份-日期-时间.json` 到手机的下载目录，**即使应用被卸载文件也还在** |
| 电脑 backups 目录 | 电脑上运行的服务每次同步后会留档一份，最多保留 30 份 |

**还原**：设置 → 自动备份 → 备份管理 → 找到要还原的时间点 → 点「还原」。
还原前系统会自动把当前数据先备份一份，所以不用担心点错。

> 「清空全部数据」不会删除备份快照，清空之后仍然可以从备份管理里还原回来。

## 与电脑同步

让手机和电脑的数据保持一致，两边各自保留一份，同步时自动合并。

**手机 APK 版**：

1. 在电脑上运行 `启动记账本.bat`，记下窗口里的「手机地址」和 6 位口令
2. 手机打开记账本 → 设置 → 与电脑同步 → 同步设置
3. 填上地址（例如 `192.168.1.7:8788`）和口令 → 点「连接并同步」

**浏览器版**：手机浏览器打开电脑上的地址并登录后，同样在设置里可以直接同步。

**同步规则**：

- 逐条比较「最后修改时间」，新的那份胜出
- 两边独有的记录都会保留，不会互相覆盖
- 删除也会同步过去，被删掉的账目不会从另一台设备跑回来
- 打开应用时自动同步一次；记账之后也会自动同步（可以在设置里关闭）

## 备份与恢复

**设置 → 账单导入 / 导出**

| 功能 | 说明 |
| --- | --- |
| 导出 CSV | 带 BOM 的 UTF-8，Excel / WPS 打开中文不乱码，包含全部字段；安卓版中会保存到系统「下载」目录 |
| 导出备份 JSON | 全量备份（账单 + 分类 + 设置），用于换设备或防丢失 |
| 从备份恢复 | 合并（按 ID 去重）或覆盖两种模式 |
| 清理重复数据 | 自动找出重复账单并删除，保留最早的一条 |
| 清理数据 | 分级清理：仅清空账单 / 仅清空分类 / 仅清空设置 / 清空备份快照 / 清除所有数据 |

### 分级清理数据

**设置 → 数据与存储 → 清理数据…**，可以按需要只清掉一部分：

| 选项 | 会清掉什么 | 会保留什么 |
| --- | --- | --- |
| 仅清空账单 | 全部账目记录 | 分类、设置、备份全部保留 |
| 仅清空分类 | 全部分类（随后装回一套默认分类） | 账目记录会保留，仍显示原来的分类名 |
| 仅清空设置 | 学期、自动分类规则、显示偏好（恢复默认） | 账目和分类都保留 |
| 清空备份快照 | 本机保存的自动备份快照 | 账目、分类、设置都不受影响 |
| 清除所有数据 | 账目、分类、设置、备份快照全部清掉 | 无 |

每个操作都会先二次确认，并在面板上写明当前有多少条数据。

> 一点说明：清理只作用于本机。如果其它设备还连着同步，删除会在下次同步时一并同步过去，
> 而不是被带回来 —— 因为「删除标记」被保留了。

> 换手机时：旧手机「导出备份 JSON」→ 把文件传到新手机 → 新手机打开应用 →
> 「从备份恢复」→ 选合并模式即可。
