# 账单导入指南

支持导入 **微信支付账单** 和 **支付宝账单** 导出的 CSV 文件，
文件只在你本机解析，不会上传到任何服务器。

---

## 一、怎么导出账单

### 微信支付

1. 微信 → 我 → 服务 → 钱包 → 账单
2. 右上角 **常见问题** → **下载账单**
3. 选择 **用于个人对账**
4. 选择要导出的月份（最长可选一个自然月）
5. 填写接收账单的邮箱 → 确认
6. 邮箱会收到一个压缩包（解压密码在微信的到账通知里）
7. 解压得到 `微信支付账单(20260901-20260930).csv`

### 支付宝

1. 支付宝 → 我的 → 账单
2. 右上角 **···** → **开具交易流水证明**
3. 选择 **用于个人对账**
4. 选择起止日期 → 填写邮箱 → 申请
5. 邮箱收到压缩包，解压得到 CSV 文件

> 支付宝导出的是 **GBK 编码**，应用会自动识别，不需要手动转码。

---

## 二、怎么导入

1. 打开应用 → 右上角 **⤓** 按钮（或「设置 → 导入微信/支付宝账单」）
2. 点虚线框选择文件，或把 CSV 直接拖进去
3. 稍等片刻，出现 **确认导入** 预览表
4. 检查表格：默认已勾选非重复的账单，可以直接逐条改分类
5. 点「导入所选」

也可以先改「导入选项」再选文件：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 自动分类 | 开 | 按来源与商品关键词自动归类 |
| 自动去重 | 开 | 交易单号已存在的标为重复，默认不导入 |
| 导入「不计收支」流水 | 关 | 如零钱通、理财、提现；导入后自动标记为不计入统计 |
| 退款流水不计入统计 | 开 | 避免退款与原始支出两边都算 |

已经选过文件后，改了选项可以点 **「用下面的选项重新解析」** 重新计算，不用重新选文件。

---

## 三、重复的账单会被自动识别

应用有两级重复识别，**默认都不会导入**，避免"先手动记了一笔、后来又导入账单"造成的重复记账：

| 级别 | 判断依据 | 预览里的标记 |
| --- | --- | --- |
| 重复 | 交易单号已存在，或日期、金额、来源、用途全部一致 | 红色「重复」 |
| 疑似重复 | 同一天、同金额、同样收/支方向（最常见的重复场景） | 黄色「疑似重复」 |

预览页顶部会提示「有 N 条疑似重复，已自动取消勾选」。把鼠标移到「疑似重复」标签上，
可以看到具体是和哪一条重复了。

**如果确实是两笔不同的消费**（比如同一天买了两杯一样价钱的奶茶），
点一下工具栏的「连疑似重复一起选」就能照样导入。

**如果已经重复导入了**，用「设置 → 清理演示/重复数据」一键清理，它会保留每条中最早的一条。

## 四、字段是怎么对应的

### 微信支付账单

| 微信字段 | 应用里的位置 |
| --- | --- |
| 交易时间 | 时间 |
| 交易对方 | **来源** |
| 商品 | **用途** |
| 收/支 | 收入 / 支出 |
| 金额(元) | 金额（`¥` 和千分位会自动去掉） |
| 支付方式 | 写入备注 |
| 当前状态 | 判断是否退款、是否跳过 |
| 交易单号 | 去重依据 |

### 支付宝账单

| 支付宝字段 | 应用里的位置 |
| --- | --- |
| 交易时间 | 时间 |
| 交易对方 | **来源** |
| 商品说明 | **用途** |
| 收/支 | 收入 / 支出 |
| 金额 | 金额 |
| 收/付款方式 | 写入备注 |
| 交易分类 | 辅助自动分类（如「餐饮美食」→ 餐饮） |
| 交易订单号 | 去重依据 |

---

## 五、自动分类是怎么判断的

按顺序匹配「来源（交易对方）+ 用途（商品）+ 交易类型」这段文本：

1. **你自己的规则**（设置 → 管理自动分类规则），优先级最高
2. **内置关键词规则**，共 19 组，例如：
   - 餐饮：食堂、美团、饿了么、瑞幸、蜜雪、烧烤、牛肉面、拉面…
   - 交通：地铁、公交、滴滴、12306、共享单车、哈啰…
   - 学习：学费、教材、打印、知网、四六级、考研…
   - 购物：淘宝、天猫、京东、拼多多、唯品会、得物…
   - 生活费：生活费、爸爸、妈妈、老爸、老妈…
3. **支付宝自带的交易分类**（如「交通出行」→ 交通）

没匹配上的会在预览里显示为「未分类」，你可以当场下拉选择。

## 六、常见问题

**Q：导入后发现有重复账单？**
先确认是不是同一份账单导了两次。应用按 **交易单号** 去重，正常不会重复。
如果确实重复了，用「设置 → 清理演示/重复数据」一键清理。

**Q：账单里有几笔没有导进来？**
预览页顶部会写「跳过 N 条」，常见原因：
- 交易状态是「已关闭 / 已撤销 / 支付失败」
- 那行没有交易时间（账单文件末尾的汇总行）
如果是「不计收支」被忽略，可以打开选项重新解析。

**Q：支付宝账单中文乱码？**
应用会自动按 GBK 解码。如果还是乱码，说明浏览器不支持 GBK 解码，换成
Chrome、Edge 或较新版的小米浏览器即可。

**Q：微信账单解压密码在哪？**
在微信的「账单下载到账通知」消息里，格式一般是几个数字。

**Q：能导入银行账单或其它 App 的账单吗？**
只要是包含「交易时间 / 交易对方 / 商品 / 收/支 / 金额」这类列名的 CSV，
应用会按通用账单解析。列名对不上时可以先用 Excel 调整表头再导入。
