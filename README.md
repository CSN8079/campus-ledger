# 大学生活记账本

一个**完全离线、数据只存在自己设备上**的记账应用。
可以在 **安卓手机（安装 APK）** 和 **电脑（浏览器）** 上使用，两边功能完全一致。

不联网、不上传、不需要账号，导出的账单文件只在本机解析。

## 先看这里：安卓安装包（APK）

**安装包位置：`dist/记账本-v1.0.0.apk`**（119 KB）

1. 把这个 APK 传到手机上（微信文件传输助手、数据线、QQ 都行）
2. 手机上点开安装，遇到"未知来源应用"提示时选择允许
3. 桌面出现「记账本」图标，点开即可使用

装好之后：**不需要电脑，不需要 WiFi，不需要流量，飞行模式下也能正常记账**。
所有数据存在手机本地，卸载应用会一起删除，请定期用「设置 → 导出备份 JSON」留档。

> 应用体积只有 119 KB，因为它没有引入任何第三方框架，只是把网页应用装进了一个自带的浏览器外壳里。
> 安装包支持 Android 8.0 及以上，小米 HyperOS 4 完全没问题。

### 关于「离线」的准确说明

| 使用方式 | 需要电脑开着吗 | 需要 WiFi / 流量吗 |
| --- | --- | --- |
| **安卓 APK** | 不需要 | **完全不需要**（飞行模式可用） |
| 手机浏览器 + 电脑局域网服务 | 需要 | 需要和电脑在同一个 WiFi |
| 电脑浏览器 | 不需要 | 不需要 |

> 为什么浏览器方式不能脱离电脑？因为手机是通过 `http://192.168.x.x` 访问电脑上的服务，
> 而浏览器在普通 http 地址下**不允许网页把自身缓存到手机里**（这是浏览器的安全限制）。
> 想要真正装在手机里独立运行，就用上面的 APK。

## 功能一览

### 1. 基础记账
- 记收入 / 支出，金额、时间、分类、账户一次填完
- 每笔账单同时记录 **来源**（交易对方 / 商家）和 **用途**（买了什么 / 做什么）
- 支持备注、多账户（微信 / 支付宝 / 银行卡 / 现金 / 校园卡 / 自定义）

### 2. 微信、支付宝账单导入
- 直接导入微信支付的账单 CSV（UTF-8）和支付宝的账单 CSV（**GBK 编码自动识别**）
- 自动识别表头、自动判断账单类型，金额带 `¥`、带千分位都能解析
- **自动分类**：内置 19 组关键词（食堂 / 美团 / 地铁 / 京东 / 妈妈转账 …），导入即归类，还能自定义规则
- **自动去重**：按交易单号识别，同一份账单导入两次不会重复记账
- 导入前有预览表格，可逐条改分类、勾选要导入的条目
- 「不计收支」的流水（零钱提现、理财收益）默认跳过，也可选择导入并自动标记为不计入统计
- 退款流水默认标记为不计入统计，避免和原始支出重复计算

### 3. 自定义分类
- 分类可自定义**名称、图标、颜色**
- 三套**分类预设包**一键生成：大学生常用（14 支出 + 8 收入）、极简 7 类、细分开销
- 分类可以**整类隐藏**（不出现在记账选择器里），也可以设为**默认不计入统计**（例如「报销」类）

### 4. 报销 / 隐藏 / 不计入统计
这是本应用最核心的差异化功能，专门解决"爸妈或别人报销"的场景：

- **报销配对**：一笔支出标记为「待报销」后立即从所有合计中排除；收到钱时点「收到报销款」，
  系统自动生成一笔配对的报销收入，**收支两笔都不计入本月账单**，但仍完整保留在明细里
- **其它排除原因**：代付、借还款、账户互转、不计收支
- **单笔隐藏**：把某笔账单设为隐藏，默认不在明细中显示
- **数据不失真**：统计页会明确告诉你「已排除 N 笔（¥X）」，随时可取消报销恢复计入统计

### 5. 周 / 月 / 学期等周期汇总
- 周期：本周、本月、上月、**本学期**、今年、全部、自定义日期区间
- 学期可在设置里自定义起止日期（默认按 2–7 月春季、9 月–次年 1 月秋季自动推断）
- 收入 / 支出 / 结余 / 日均支出
- 分类占比环形图、收支趋势图、支出 TOP 来源、账户分布

### 6. 数据安全
- 导出 **CSV**（带 BOM，Excel 打开中文不乱码）
- 导出 / 恢复 **JSON 全量备份**（安卓版里会存到系统的「下载」目录）
- 一键检测并清理重复账单
- 存储优先用 IndexedDB，浏览器不支持时自动降级到 localStorage

## 在电脑上运行

双击 `启动记账本.bat`，浏览器会自动打开记账本。也可以：

```bash
npm start            # 启动本地服务并打开浏览器
node tools/serve.js  # 只启动服务
```

命令行会打印出一个手机可访问的局域网地址（如 `http://192.168.1.7:8788/`），
手机连同一个 WiFi 时可以用浏览器打开（但这个方式需要电脑开着，见上面的说明）。

> 需要 Node.js 18 以上，仅用于启动本地服务；应用本身零依赖。


## 重新打包 APK

```bash
npm run apk:tools     # 首次：下载 JDK 与安卓 SDK 到 .buildtools（约 400MB，便携解压）
npm run apk:build     # 打包，产物在 dist/
npm run apk:verify    # 校验 APK 结构、资源与签名
```

打包过程**不需要 Gradle，也不需要联网下载任何第三方库**，
只用 JDK 自带的 javac、安卓 SDK 的 aapt2/d8/zipalign/apksigner。
详见 [docs/Android打包指南.md](docs/Android打包指南.md)。

## 数据与隐私

- 所有数据保存在设备的本地数据库里，**不会上传到任何服务器**
- 安卓版内置的网页外壳会拦截一切外部请求，应用不发起任何网络访问
- 建议定期用「设置 → 导出备份 JSON」留一份存档
- `.gitignore` 已排除本地数据与备份文件，不会误提交到 Git

## 常见问题

**Q：手机装了 APK，飞行模式下能用吗？**
能。APK 版不需要任何网络，程序和数据都在手机里。

**Q：APK 卸载后数据还在吗？**
不在。安卓卸载应用会清除应用数据，请先导出 JSON 备份。
换手机时：旧手机导出备份 → 把文件传到新手机 → 新手机「从备份恢复」。

**Q：电脑上的浏览器版本和手机 APK 的数据互通吗？**
不互通，各自存在自己设备上。可以通过「导出备份 JSON / 从备份恢复」在设备之间搬数据。

**Q：支付宝账单导入乱码怎么办？**
支付宝导出的是 GBK 编码，应用已自动识别。如果仍然乱码，说明浏览器太旧（不支持 GBK 解码），换 Chrome / Edge 或直接用 APK。

**Q：导入的账单分类不对？**
在「设置 → 管理自动分类规则」里加自己的关键词，自定义规则优先级高于内置规则。

**Q：APK 安装时提示"未知来源"？**
这是安卓对非应用商店安装包的标准提示，选择允许即可。应用是自签名的，没有上架应用商店。
