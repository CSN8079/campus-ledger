# 大学生活记账本

一个**完全离线、数据只存在自己设备上**的记账应用。
电脑和安卓手机上都能用，功能一致，两边可以互相同步，并且都有自动备份。

## 更新日志

### v2.1.1 —— 报销的钱从账目里的收入抵消

- **报销不用再手输金额**：配对时上面勾「这笔钱是哪几笔收入进来的」，下面勾「抵消哪些垫付」，
  金额自动算出来；被抵消的垫付不计入统计，没抵消到的仍然算你的支出
- 这笔收入里「垫付返还」的部分不算收入，只有对方多给的那部分才算（开关可关）
- 后来又收到一笔钱再配一次时，之前抵掉的不会被冲掉；取消配对不再删掉你的收入记录
- 概览「待报销」→「去处理」会**直接跳到明细里那一行**：自动切到「只看待报销」、滚动定位并高亮

### v2.1.0 —— 电脑端自动记账 + 手机一键配对

- **账单导入箱**：电脑上把微信/支付宝导出的账单文件丢进「账单导入箱」文件夹，电脑自动解析、去重、
  合并进数据（重复的按文件里的数据更新），手机下次同步就能看到——**不用再一条条手动导**
- **手机一键配对**：手机 App 里点「自动找电脑（同一 WiFi）」，自动填好地址和访问口令，不用手输；
  电脑上可随时点「打开配对窗口（2 分钟）」放行新设备（口令不会一直在网络里广播）

### v2.0.2 —— 假期不计入统计、报销一次抵多笔、支出走势折线图

- **假期不计入统计（测试版）**：寒暑假、国庆这些时间人在家，校园生活口径对不上。
  可以自己定日期区间（提前回校就把结束日改早），这段的账目留在明细但不参与周/月/学期合计；
  还能**联网取一次全国节假日**直接加进来，并在假期**开始前 / 结束前提醒**，处理完提醒才消失
- **报销更贴近实际**：只报一部分时，剩下自己承担的仍然算支出；报多了，只有多出来的算收入；
  **一次转账可以抵消好几笔垫付**（先垫先抵）。代付、借出去的钱也能「收回来了」走同一套配对
- **导入重复时默认保留导入的数据**：文件里的时间/商家/交易单号最准，就地更新原来那一笔，
  你自己改过的分类、账户、备注、报销标记都保留（顺手修好了「同日同额疑似重复」一直没生效的问题）
- **概览新增「支出走势」折线图**：一眼看出钱花在哪几天
- 「记一笔」的**分类可以自己排顺序**（常点的放前面）
- AI 助手入口挪到**顶栏常驻按钮**，概览页顶部也有一个卡片，不用再去设置里找
- 键盘遮挡：面板自动抬到键盘上方，滚动改成**合并 + 平滑**，不再一跳一跳眼花

### v2.0.1 —— 打字不再被键盘挡住

- **手机上点输入框，整个面板会自动抬到键盘上方**，输入框和「历史联想」候选都看得见，
  最下面那个输入框也不会再被键盘压住
- 时间可以精确到 **1 分钟**（以前是 5 分钟一档）
- 修掉「在面板里选完分钟，整个面板跳回最上面」的问题
- **AI 现在能读到每一笔账目**（金额、时间、分类、来源、用途）：可以直接回答
  「这周花了多少」，也能按「最近的一笔」精确定位并改动；合计数字由应用自己算，不靠模型心算

### v2.0.0 —— 内置 AI 助手

- **新增内置 AI 助手**：填一个 AI 接口（例如 DeepSeek），就能用说话的方式批量整理账目——
  批量改分类、批量设为「不计入统计」、重命名分类。AI 只给建议，改动要你点确认才写入。
  这是本次最大的变化，所以版本号从 2.0 开始计。
- 外观主题可选 **跟随系统 / 浅色 / 深色**，手机切到深色模式应用会跟着变。
- 记账时「来源 / 用途」支持**历史联想**：输入几个字就列出以前填过的写法，点一下自动填充。
- 概览有**支出走势折线图**；「记一笔」里的分类顺序可以自己调（设置里或表单里都行）。
- 导入账单遇到重复时，默认**用文件里的数据更新原来那一笔**（保留你改过的分类、账户、备注）。
- 修掉同步后分类重复的问题（同名分类不再变成两个「餐饮」）。

### v1.1.x 及更早

微信 xlsx 账单导入、排除规则完全交给用户决定、图片报告抬头可自定义、分级清理数据、
同步进度与口令记住、横屏布局、深色模式系统栏透明、走势图日期斜排等。

## 功能一览

### 记账
- 记收入 / 支出，金额、时间、分类、账户一次填完
- 日期时间用的是**自己画的日历面板**，不是系统原生控件，手机上不再弹出又丑又挡屏的系统选择器
- 每笔账单分开记录 **来源**（交易对方 / 商家）和 **用途**（买了什么 / 做什么）
- 时间可以精确到 **1 分钟**（选择器里分钟是 0-59 全给，不再是 5 分钟一档）
- **历史联想**：填「来源」或「用途」时输入几个字，就会列出以前填过的写法（按用过次数排序，
  还会标出「常记作 餐饮」），点一下就能套用，统计口径自然就统一了

### 假期不计入统计（测试版）
- 设置 → 学期设置 → **假期设置**，自己定日期区间（寒假、暑假、国庆、提前回校都行）
- 假期里的账目**留在明细里**，但不参与本周/本月/本学期等任何合计
- 可以**联网获取全国节假日**：设置里点一下「从网上获取」，勾选后直接加进来；
  取不到也能把 JSON 粘贴进去，数据源地址可以自己换
- **开始前 / 结束前会提醒**：概览页出现一张卡片，写着还剩几天，
  可以「设为假期（不计入统计）」「自己改时间」「照常计入」——**处理完提醒才消失**
- 单个开关「假期期间不计入统计」随时可以关掉，账目立刻恢复参与合计

### 报销 / 收回垫付
- **只报一部分**：花 38、家里给 20，则 20 不计入统计，剩下 18 仍然算你的支出
- **报多了**：原支出全额不计入，多出来的那部分才计入收入（可以关掉）
- **一次转账抵消多笔垫付**：先垫的先生效，没抵消到的仍然算你的支出
- 代付、借出去的钱在账单详情里点「收回来了」，和报销用的是同一套配对
- 一笔账可以「又还了一部分 / 改金额」，更新原来那一笔，不会多出记录

### 外观主题
- 设置 → 显示与偏好 → 外观主题，可选 **跟随系统 / 浅色 / 深色**
- 选「跟随系统」后，手机切到深色模式应用会立刻跟着变，不用手动切换
- 深色模式下系统栏（含全面屏手势条）是透明的，屏幕最下方不会再出现一条白色横条

### 微信、支付宝账单导入
- **微信支付账单**：支持 `.xlsx`（微信默认导出的就是 Excel 格式）和 `.csv` 两种，直接拖进来即可
- **支付宝账单**：支持 `.csv`（支付宝导出的是 **GBK 编码，自动识别**，不会乱码）
- 内置 19 组关键词自动分类，可自定义规则
- **两级重复识别**：交易单号相同 → 标记「重复」；同一天同金额 → 标记「疑似重复」。
  两者默认都不勾选，避免"先手动记了一笔、后来又导入账单"造成的重复记账
- **默认什么都不排除**：账单里标「不计收支」的流水也照样计入合计，应用不会擅自替你判断。
  想少算这类流水（余额宝转入转出、花呗还款等），在导入面板里改成「不计入合计」即可；
  预览表最后一列还能逐条点着切换
- 「不计收支」的流水会**自动判断收支方向**（余额宝收益显示 +0.02、转出显示 -150.00），
  不再一律当成支出显示成负数
- **每一行都有明确归宿**：预览页会写清「文件里共 N 行数据 → 生成 M 条记录，另有 X 行无法识别」，
  并分别列出新增、重复、疑似重复、不计入统计各多少条，不会让你猜数据去哪了
- 导入前有预览表格，可逐条改分类、勾选要导入的条目

### 报销 / 隐藏 / 不计入统计
- **报销配对**：支出标记「待报销」后立即从所有合计中排除；收到钱时点「收到报销款」，
  自动生成配对的报销收入，**收支两笔都不计入本月账单**，但记录完整保留
- 其它排除原因：代付、借还款、账户互转、不计收支
- 单笔账单可隐藏；分类可整类隐藏，也可设为默认不计入统计
- 统计页明确写出「已排除 N 笔（¥X）」，随时可取消报销恢复计入

### 周期统计
- 本周、本月、上月、**本学期**（起止日期可自定义）、今年、全部、自定义区间
- 收入 / 支出 / 结余 / 日均支出，分类占比环形图、收支趋势图、支出 TOP 来源、账户分布

### 导出报表（给爸妈看）
- **导出 Excel**：真正的 `.xlsx` 文件，含 4 个工作表（周期汇总、账目明细、分类汇总、每日收支），
  Excel / WPS 直接打开，中文不乱码
- **生成图片报告**：一页纸的收支报告（1080 宽 PNG），浅色配色，直接发微信给父母看
- **图片抬头可以自己写**：默认「大学生活记账本」，可以改成「10 月生活费账目」之类，
  生成时会记住，下次继续用

### 内置 AI 助手（v2.0 新增）
- 在 **设置 → 内置 AI 助手** 里填任意兼容 OpenAI 格式的接口（例如 DeepSeek）：
  接口地址、API 密钥、模型名，填好保存即可
- 然后直接用说话的方式批量整理账目：
  「把杭州深度求索的充值从其他改成数码」「把教材费都设成不计入统计」
  「最近的一笔账目的分类改成交通」「这周一共花了多少」
- **AI 只给建议，不自己动手**：改动会先列成「待确认的改动」，写明会影响几条、
  举出例子，你点「执行这一项」或「全部执行」之后才真正写入
- 手机 App 走系统原生请求，不受网页跨源限制；手机不方便直连时，
  也可以让电脑上的服务代为转发（电脑服务只允许转发到公网地址，不会变成内网探测工具）
- **AI 能看到每一笔账目**（金额、时间、分类、来源、用途），所以问「这周花了多少」「总收入多少」
  它直接就能答；「最近的一笔」这类说法也能精确定位。凡是合计数字，都由应用自己算，不靠模型心算
- 接口地址和密钥只保存在这台设备上；每次提问会把最近的账目明细一并发给 AI 服务商（最多 300 笔），
  介意的话可以不使用这个功能

### 自动记账（电脑端）
- 电脑上运行服务后，会出现一个「**账单导入箱**」文件夹
- 把微信或支付宝导出的账单文件（.csv / .xlsx）**丢进这个文件夹**，电脑自动：
  解析（自动识别 UTF-8 / GBK 编码）→ 去重（重复的用文件里的数据更新原来那一笔）→ 合并入库 → 备份
- 处理过的原文件会被挪到「已导入」子文件夹，解析失败的在「解析失败」里，都不会重复处理
- 手机打开 App 会自动同步一次，所以你在电脑上丢完文件，手机上直接就能看到
- 导入箱里的文件不会被提交到 Git（已在 .gitignore 里排除）

### 电脑与手机同步
- 手机 App 里填上电脑的地址和口令，就能把两边数据合并到一起
- **自动比较新旧**：逐条比较「最后修改时间」，新的那份胜出；删除也会同步过去，不会"复活"
- **同步进度看得见**：面板上有进度条，实时显示「上传中 20%」「电脑合并中 60%」等步骤，
  完成后给出上传 / 下载 / 电脑合计的条数
- **口令只输一次**：记住设备后不再要求输入；连不上时 20～30 秒内报错，不会一直卡住
- 打开应用时自动同步一次，记账之后也会自动同步
- **手机一键配对**：手机 App → 设置 → 与电脑同步 → 点「📶 自动找电脑（同一 WiFi）」，
  手机会自动找到电脑并填好地址和口令，不用手输；电脑上点「打开配对窗口（2 分钟）」可临时放行新设备
- 也可以只用浏览器同步（手机浏览器打开电脑的服务即可）
- **分类不会变成两个**：同名同类型的分类在每台设备上算出来的编号都一样，
  同步时会自动合并成一条，不会再出现「餐饮 ×2」「交通 ×2」

### 自动备份（电脑和手机都有）
| 位置 | 方式 |
| --- | --- |
| 手机 App | 自动把整份数据存成快照，同时往手机「下载」目录写一份 JSON 备份文件 |
| 手机 / 电脑浏览器 | 自动在本机数据库里保留最近 N 份快照，可在「自动备份 → 备份管理」里一键还原 |
| 电脑服务端 | 每次同步后自动在 `backups/` 目录留档，最多保留 30 份 |

### 分级清理数据

**设置 → 数据与存储 → 清理数据…**，每一项只清掉你选的那部分，不会再"一次清过头"：

| 选项 | 会清掉什么 | 会保留什么 |
| --- | --- | --- |
| 仅清空账单 | 全部账目记录 | 分类、设置、备份全部保留 |
| 仅清空分类 | 全部分类（随后装回一套默认分类） | 账目会保留，仍显示原来的分类名 |
| 仅清空设置 | 学期、分类规则、显示偏好（恢复默认） | 账目和分类都保留 |
| 清空备份快照 | 本机保存的自动备份 | 账目、分类、设置都不受影响 |
| 清除所有数据 | 账目、分类、设置、备份快照全部清掉 | 无 |

每项操作都会先二次确认，面板上会写明当前有多少条数据。

### 横屏与大屏

- 手机横屏时自动切换成**左侧导航栏**布局，把宝贵的竖向空间让给内容
- 电脑、平板等宽屏下内容会**铺满可用宽度并居中**，右侧不再留大片空白

### 访问控制
- 局域网访问需要**访问口令**（首次启动自动生成 6 位数字，显示在电脑的命令行窗口里）
- 勾选「记住这台设备」后长期免输，**自动登录**
- 电脑本机访问免口令；连续输错 8 次会锁定 5 分钟
- 口令保存在 `.server.json`，可随时修改

## 快速开始

### 电脑上运行

双击 `启动记账本.bat`，命令行窗口会显示：

```
电脑上打开：http://127.0.0.1:8788/   （本机免口令）

手机上打开（需与电脑在同一 WiFi）：
  http://192.168.1.7:8788/

┌──────────────────────────────────────────────┐
│   手机首次访问需要输入访问口令                │
│       口  令 ： 482915                        │
└──────────────────────────────────────────────┘
```

手机浏览器打开上面的地址 → 输入口令 → 勾选「记住这台设备」→ 以后再打开就不用输了。

### 手机 APK 连电脑同步

1. 在 APK 里进入 **设置 → 与电脑同步 → 同步设置**
2. 填「电脑地址」（如 `192.168.1.7:8788`）和窗口里显示的 6 位口令
3. 点「连接并同步」

之后手机不用打开浏览器，直接点桌面图标就能记账并同步。

## 数据与隐私

- 所有数据保存在设备本地，不上传任何服务器；同步只在你自己的电脑和手机之间进行
- 安卓外壳会拦截一切非局域网请求，应用无法访问公网
- `.gitignore` 已排除 `.server.json`、`.sync-data.json`、`backups/` 与各类备份文件
- 建议保持自动备份开启；换设备时用「从备份恢复」搬运数据

## 常见问题

**Q：手机第一次打开要输口令，以后还要输吗？**
不用。勾选「记住这台设备」后会长期免输（Cookie 有效期一年）。换了浏览器或清了浏览数据就要再输一次。

**Q：忘记了访问口令？**
口令显示在电脑上运行服务的窗口里；也可以打开项目根目录的 `.server.json` 查看。
删掉这个文件再重启服务会生成新口令。

**Q：执行了一次"清空全部数据"，还能恢复吗？**
能。清空操作会保留应用内的备份快照，去「设置 → 自动备份 → 备份管理」里选一个时间点还原即可。

**Q：手动记的账和导入的账单重复了怎么办？**
导入时同一天同金额的记录会被标成「疑似重复」并自动取消勾选，确认不是同一笔再手动勾上即可。
已经重复了的话，用「设置 → 清理演示/重复数据」一键清理。

**Q：同步会不会把我手机上的数据覆盖掉？**
不会。同步是逐条比较「最后修改时间」后合并，两边独有的记录都会保留，冲突时保留后改的那一份。

**Q：支付宝账单导入乱码？**
支付宝导出的是 GBK 编码，应用已自动识别。仍然乱码说明浏览器太旧，换 Chrome / Edge 或直接用 APK。

**Q：APK 安装时提示"未知来源"？**
这是安卓对非应用商店安装包的标准提示，选择允许即可。应用是自签名的，没有上架应用商店。
