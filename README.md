# 大学生活记账本

一个**完全离线、数据只存在自己设备上**的记账应用。同一套代码可以在
**电脑（Windows / macOS / Linux 浏览器）** 和 **安卓手机（含小米 HyperOS 4）** 上运行，
手机上可以「添加到主屏幕」，像原生 App 一样独立打开、断网可用。

不联网、不上传、不需要账号，导出的账单文件只在本机解析。

## 功能一览

### 1. 基础记账
- 记收入 / 支出，金额、时间、分类、账户一次填完
- 每笔账单同时记录 **来源**（交易对方 / 商家）和 **用途**（买了什么 / 做什么）
- 支持备注、多账户（微信 / 支付宝 / 银行卡 / 现金 / 校园卡 / 自定义）

### 2. 微信、支付宝账单导入
- 直接导入微信支付的账单 CSV（UTF-8）和支付宝的账单 CSV（**GBK 编码自动识别**）
- 自动识别表头、自动判断账单类型，金额带 `¥`、带千分位都能解析
- **自动分类**：内置 19 组关键词（食堂 / 美团 / 地铁 / 京东 / 妈妈转账 …），导入即归类，还能自定义规则
- **自动去重**：按交易单号识别，同一份账单导入两次不会重复记账
- 导入前有预览表格，可逐条改分类、勾选要导入的条目
- 「不计收支」的流水（零钱提现、理财收益）默认跳过，也可选择导入并自动标记为不计入统计
- 退款流水默认标记为不计入统计，避免和原始支出重复计算

### 3. 自定义分类
- 分类可自定义**名称、图标、颜色**
- 三套**分类预设包**一键生成：大学生常用（14 支出 + 8 收入）、极简 7 类、细分开销
- 分类可以**整类隐藏**（不出现在记账选择器里），也可以设为**默认不计入统计**（例如「报销」类）

### 4. 报销 / 隐藏 / 不计入统计
这是本应用最核心的差异化功能，专门解决"爸妈或别人报销"的场景：

- **报销配对**：一笔支出标记为「待报销」后立即从所有合计中排除；收到钱时点「收到报销款」，
  系统自动生成一笔配对的报销收入，**收支两笔都不计入本月账单**，但仍完整保留在明细里
- **其它排除原因**：代付、借还款、账户互转、不计收支
- **单笔隐藏**：把某笔账单设为隐藏，默认不在明细中显示
- **数据不失真**：统计页会明确告诉你「已排除 N 笔（¥X）」，随时可取消报销恢复计入统计

### 5. 周 / 月 / 学期等周期汇总
- 周期：本周、本月、上月、**本学期**、今年、全部、自定义日期区间
- 学期可在设置里自定义起止日期（默认按 2–7 月春季、9 月–次年 1 月秋季自动推断）
- 收入 / 支出 / 结余 / 日均支出
- 分类占比环形图、收支趋势图、支出 TOP 来源、账户分布

### 6. 数据安全
- 导出 **CSV**（带 BOM，Excel 打开中文不乱码）
- 导出 / 恢复 **JSON 全量备份**（合并去重或覆盖还原）
- 一键检测并清理重复账单
- 存储优先用 IndexedDB，浏览器不支持时自动降级到 localStorage

## 快速开始

### 电脑上运行

双击项目里的 **`启动记账本.bat`**，浏览器会自动打开记账本。

也可以手动启动：

```bash
npm start          # 启动本地服务并打开浏览器
# 或
node tools/serve.js
```

> 需要 Node.js 18 以上（仅用于启动本地服务，应用本身零依赖）。

### 安卓手机上运行（小米 HyperOS 4 等）

1. 在电脑上双击 `启动记账本.bat`，命令行会打印出一行手机可访问的地址，例如
   `http://192.168.1.7:8788/`（手机需和电脑连同一个 WiFi）
2. 手机用 **Chrome / Edge / 小米浏览器** 打开这个地址
3. 打开浏览器菜单 → **添加到主屏幕**
4. 桌面会出现「记账本」图标，点开就是全屏应用，**断网也能用**

> 想让手机独立使用、不依赖电脑开服务，见 [打包成安卓 APK](docs/Android打包指南.md)。
> 打包后 APK 装到手机上就是彻头彻尾的单机应用。

## 测试

```bash
npm test                  # 核心逻辑测试（71 项，纯 Node，无需浏览器）
npm run test:browser      # 浏览器端到端测试（63 项，会启动无头 Chrome 并截图）
```

`npm test` 覆盖存储降级、账单编码识别（UTF-8 / GBK）、微信与支付宝账单解析、
自动分类、去重、周期合计、报销排除、隐藏、备份导入导出。

`npm run test:browser` 用 Chrome DevTools 协议驱动真实浏览器，跑完整界面流程
（记账、报销、导入、统计、分类管理、主题切换），并检查无横向溢出、无控制台报错，
最后把各页面截图输出到 `docs/screenshots/`。

## 数据与隐私

- 所有数据保存在浏览器的本地数据库里，**不会上传到任何服务器**
- 导出的账单文件在本机解析，网络请求只用于加载应用自身的静态文件
- 建议定期用「设置 → 导出备份 JSON」留一份存档
- `.gitignore` 已排除本地数据与备份文件，不会误提交到 Git

## 常见问题

**Q：手机上打开是网页，能像 App 一样用吗？**
可以。添加到主屏幕后，它有独立图标、全屏打开、离线可用，和原生 App 体验几乎一致。

**Q：换手机或清空浏览器数据后账单会丢吗？**
浏览器数据会随"清除浏览数据"一起删除。请定期导出 JSON 备份，换设备时用「从备份恢复」还原。

**Q：支付宝账单导入乱码怎么办？**
支付宝导出的是 GBK 编码，应用已自动识别。如果仍然乱码，说明浏览器太旧（不支持 GBK 解码），换 Chrome / Edge 即可。

**Q：导入的账单分类不对？**
在「设置 → 管理自动分类规则」里加自己的关键词，自定义规则优先级高于内置规则。

**Q：如何批量把一批账单改成不计入统计？**
在明细里用「按分类」「按账户」筛选，或直接给某个分类设为「默认不计入统计」，之后导入的同类账单会自动排除。
